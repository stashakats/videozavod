# videozavod

## Что это

videozavod — локальная установка генератора коротких видео. Конкретные продуктовые функции не заданы; установка создаёт главную страницу, закрытую страницу администратора со спецификацией и журналом решений, проверку проекта и подготовленную интеграцию с Convex. «Работает» означает, что приложение открывается локально, `/admin` доступна после входа, а `pnpm check` проходит.

## Состав

Node.js 24 LTS, pnpm 12, Next.js 16 с App Router, React 19, TypeScript, Tailwind CSS, Convex, Vitest, ESLint и Prettier. Цель будущего деплоя — Vercel; публикация не входит в эту установку. Живая база данных появится после входа владельца в Convex и запуска CLI.

## Решения

Решения записаны в [журнале](journal.md), новые сверху:

- ⚖️ adopt-spec-driven-company — истина живёт в `docs/`, агенты исполняют, статус виден.
- ⚖️ convex-prepared-no-login — интеграция подготовлена локально; облачный доступ остаётся за владельцем.
- ⚖️ terminal-admin-desk — админка показывает производство и сигналы экспериментов в светлом многопанельном дисплее.

## Где что лежит

- `src/` — страницы приложения, компоненты и защита маршрутов.
- `convex/` — схема и конфигурация Convex; серверных функций пока нет.
- `docs/admin-desk.md` — устройство рабочего дисплея админки.
- `docs/refs.md` — источники визуальных и рабочих паттернов.
- `docs/` — эта сводка, журнал и правила зон.
- `.env.local` — локальный пароль админки; файл с ключами не коммитится.
- `.env.local.example` — имена переменных для локальной настройки.

## Проверка и статус

`pnpm check` запускает форматтер, ESLint, проверку типов и Vitest. `pnpm dev` запускает приложение на `http://localhost:3000`. Статус последней проверки виден на `/admin`; содержимое документов читается с диска при запросе. Для живой базы данных владелец запускает `npx convex dev` и входит в Convex.
